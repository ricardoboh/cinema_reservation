# React frontend

See [Phase 1 guide](../docs/cinema-management.md) for startup, demo administration, APIs, booking and limitations.

Routes: /, /movies, /movies/:id, /book/:screeningId, /reservations, /approver, /admin, /admin/movies, /admin/halls, /admin/screenings. Dark/light theme persists in local storage.

Run npm.cmd ci, npm.cmd run dev; checks: npm.cmd run lint and npm.cmd run build (TypeScript + Vite).
